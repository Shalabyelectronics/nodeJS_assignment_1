# Assignment 1 — JavaScript Fundamentals

> **Course:** Node JS BootCamp  
> **Module / Topic:** Part 1 — JavaScript Core, ES6+, Async Promises & Essay Review

## About This Assignment

This repository contains my solutions for **Assignment 1** of the **Node JS BootCamp**. It covers core JavaScript fundamentals (type conversion, loops, array methods like `filter` and `map`, spread/rest operators, destructuring, arrow functions, promises), conceptual essay questions (hoisting, TDZ, `==` vs `===`, `try...catch`, coercion), and a LeetCode bonus problem (_Counter II_).

## Objectives

- Solve 15 JavaScript coding exercises (`assignment1.js`)
- Answer 5 core JavaScript conceptual essay questions (`assignment1.js`)
- Complete the LeetCode _Counter II_ bonus challenge (`bonus.js`)

## Tech Stack
